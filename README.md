# ICT932 — Secure Web Application with DevSecOps Pipeline

## Project Overview
A secure web application built using DevSecOps principles for ICT932 Cybersecurity Testing and Assurance.

- Prasanna Shrestha — Secure App Developer

## Repository Structure
- `/src` — Django Task Manager application
- `/docs` — Project documentation
- `/tests` — Test files
- `/ci-cd` — CI/CD pipeline configurations

## Tools Used
- GitHub Actions (CI/CD)
- OWASP ZAP (DAST)
- SonarQube (SAST)
- Nikto (Web Scanner)

## Current Features
- Secure login and registration
- Role-Based Access Control (Admin vs User)
- Two-Factor Authentication (2FA) with Google Authenticator
- Task manager features
- Brute force protection
- XSS prevention
- Session timeout
- Security event logging
